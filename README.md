# Audi MMI 3G research notes

Audi MMI 3G / QNX / SH4 的实验记录与复现入口。当前为研究资料库，不是可安装的 CarPlay 产品，也不是刷机包。

## 已验证的进展

- K0942 固件可正确提取并解析 QNX SH/LZO IFS。
- 定制 SH7785/QEMU 实验运行到了真实 NVIDIA 图形驱动链，日志出现 800×480、32bpp 模式设置。
- 对 `devg-nv` 取指与实际装载基址进行了核对。
- 找到 `nMSDKIPC` 与完整 EFS 媒体服务依赖，明确下一步验证顺序。

## 尚未实现

- `gf_dev_attach()` 仍失败，未取得经过验证的真实 MMI framebuffer。
- 没有真实数值胎压页面、完整 MMI 桌面或 CarPlay 成功运行的证据。
- 截图重绘、资源存在、编译成功和进程启动均不等于实机功能成功。

详见 [模拟器阶段报告](docs/simulator-status.md) 和 [复现路线](docs/reproduction.md)。

## 原生 CarPlay 专项

[CarPlay 研究源码与进度](carplay/README.md)：协议核心、构建审计工具及 SD 诊断阶段记录。尚未完成可用接收器，不是可安装的 CarPlay 产品。

## 发布范围

不包含原厂固件、固件解包出的专有二进制、内存转储、凭据、个人信息和用户车辆标识。
公开原始自编代码前必须完成内容与许可证核查。第三方代码保留其原许可证和归属，不随意重新许可。
第一版公开的是已核查的阶段记录；定制源码的私有归档正在核对，尚未完成公开源码发布，不应把本仓库描述为完整可构建模拟器。

## 安全边界

只在隔离副本上研究。不要将模拟器镜像写入量产车机。K0942 的静态结论不自动适用于其他区域或 P0710。

## 更新规则

只发布有证据的新进展。每次更新写清验证环境、方法、结果及仍未解决的问题；未知结果不提升为成功。
不自动触发车辆操作、刷机、远程服务修改或大规模下载。
